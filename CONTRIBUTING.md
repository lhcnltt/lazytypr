# Contributing

lazytypr begins as a maintainer-led public project. Bug reports and focused
design discussion are welcome. Before opening an outside pull request, obtain
agreement from `@lhcnltt` on an issue. Unsolicited PRs may be closed so the
architecture, privacy contract, and phase plan remain coherent.

Issues should include the expected and observed behavior, platform, exact
revision/version, minimal reproduction, evidence level, and sanitized logs.
Never submit credentials, recordings, ordinary user speech, IBM-confidential
information, or third-party proprietary material.

Contributions are provided under the repository MIT license. By submitting a
contribution, you represent that you have the right to do so under those terms.
Copied or substantially adapted work requires prior review, SPDX attribution,
an immutable source revision, hashes where applicable, retained notices, and a
record in `docs/PROVENANCE.yaml`.

Implementation changes require an accepted GSD phase plan, a `phase/*` branch,
tests proportional to risk, `reuse lint`, and a pull request reviewed by the
CODEOWNER. A formal Contributor Covenant is deferred until the project has a
dedicated private conduct-report channel.
