# Security Policy

## Supported releases

No executable release exists. During planning, only the current `main` branch
documentation is maintained. After v1, the latest supported release line will
receive security fixes; this table will name exact versions and end dates.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Once the GitHub
repository exists, use private vulnerability reporting at:

`https://github.com/lhcnltt/lazytypr/security/advisories/new`

Until that channel exists, do not transmit secrets or exploit material; contact
the maintainer through an agreed private channel first. Include affected
version/commit, platform, impact, reproducible steps, and any safe mitigation.
The maintainer will acknowledge receipt, assess severity, coordinate a fix, and
credit the reporter if requested.

The architecture and threat model are in
[SECURITY_AND_PRIVACY_DESIGN.md](docs/SECURITY_AND_PRIVACY_DESIGN.md).
