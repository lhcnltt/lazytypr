<interfaces>
`WindowsFocusPasteAdapter` implements Plan 01-04's `FocusPastePort`. It invokes only the fixed built helper path with `execFile`, writes one protocol request to stdin, enforces 4096-byte stdout/stderr caps and a two-second process timeout, parses one strict response, and maps it to `Result&lt;FocusTarget | PasteOutcome, AppError&gt;`. Target values exist only in the active main session and must never enter a renderer, log, report, fixture output, path, or persisted file.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Electron main to Windows helper | A privileged local child receives a bounded target operation and returns a typed result. |
| helper to Win32 focus/input APIs | OS target identity and keystroke injection require exact verification and fail-closed handling. |
| pinned upstream evidence to local C source | Adapted code carries supply-chain and licensing obligations. |

## STRIDE Threat Register — ASVS L2

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-LT01-SC | Tampering | native source/dependencies | high | mitigate | No new package; pinned upstream revision, direct SPDX attribution, target-native toolchain, later provenance/reuse gate. |
| T-LT01-06-S | Spoofing | HWND/PID target | high | mitigate | Validate existence/ownership, activate exact target, poll exact foreground, then revalidate immediately before SendInput. |
| T-LT01-06-T | Tampering | helper request/response | high | mitigate | Version/request ID, strict fields, 4096-byte caps, unknown-key rejection, fixed executable path, no shell. |
| T-LT01-06-R | Repudiation | native outcome | medium | mitigate | Finite request-correlated outcome codes with no content or identity logs. |
| T-LT01-06-I | Information Disclosure | target/clipboard/child output | high | mitigate | No clipboard text in protocol; target only active-session memory; raw output never reaches logs/errors/evidence. |
| T-LT01-06-D | Denial of Service | hung helper/foreground polling | medium | mitigate | 750 ms activation poll, two-second child timeout, AbortSignal kill, caps, bounded concurrency. |
| T-LT01-06-E | Elevation of Privilege | SendInput to wrong/elevated target | critical | mitigate | Fail on access/identity/activation mismatch, never elevate, never choose another target or use shell fallbacks. |

Any critical or high finding blocks plan completion; medium findings require mitigation under ASVS L2.
</threat_model>
