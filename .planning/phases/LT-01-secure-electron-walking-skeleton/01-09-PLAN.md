<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| main snapshots to renderer DOM/accessibility tree | Public state must be truthful and free of sensitive main-only data. |
| user controls to preload/main | Semantic controls request narrow actions but cannot grant themselves privilege. |
| adapted interaction evidence to original UI | Visual/interaction inspiration must not copy branding/assets without provenance. |

## STRIDE Threat Register — ASVS L2

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-LT01-SC | Tampering | React renderer packages | high | mitigate | Consume exact reviewed lockfile; no component/icon/font registry or new package. |
| T-LT01-09-S | Spoofing | renderer outcome/status | high | mitigate | Render only main-originated validated snapshots and finite message keys; renderer never advances state. |
| T-LT01-09-T | Tampering | auto-paste UI state | high | mitigate | Main-side acknowledged strict IPC, idle-only mutation, per-session snapshot; renderer state is not authority. |
| T-LT01-09-R | Repudiation | copy/cancel outcome | medium | mitigate | Exact mutually consistent labels tied to copied/pasted booleans and commit-barrier state. |
| T-LT01-09-I | Information Disclosure | DOM/a11y/live regions | high | mitigate | Role-redacted payload, typed fixed copy, privacy tests across visible and accessible output. |
| T-LT01-09-D | Denial of Service | repeated events/animation/layout | medium | mitigate | Disposers, busy deduplication, bounded text, limited motion, wrap/vertical growth tests. |
| T-LT01-09-E | Elevation of Privilege | renderer controls/preload | critical | mitigate | Semantic UI invokes named bridge methods only; no raw Electron/IPC/OS capability or arbitrary payload. |

Any critical or high finding blocks plan completion; medium findings require mitigation under ASVS L2.
</threat_model>
