<interfaces>
`MacosFocusPasteAdapter` implements Plan 01-04's `FocusPastePort`. It invokes only the fixed built helper path with `execFile`, writes one protocol request to stdin, enforces 4096-byte stdout/stderr caps and a two-second process timeout, parses one strict response, and maps it to `Result&lt;FocusTarget | PasteOutcome, AppError&gt;`. Clipboard-only mode must never require Accessibility. Target values exist only in the active main session and never enter renderers, logs, reports, fixture output, or persistence.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Electron main to macOS helper | A privileged local child receives a bounded target operation and returns a typed result. |
| helper to AppKit/Accessibility/CGEvent | OS identity and keystroke injection require exact verification and fail-closed handling. |
| pinned upstream evidence to local Swift source | Adapted code carries supply-chain and licensing obligations. |

## STRIDE Threat Register — ASVS L2

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-LT01-SC | Tampering | native source/dependencies | high | mitigate | No new package; pinned upstream revision, direct SPDX attribution, target-native toolchain, later provenance/reuse gate. |
| T-LT01-07-S | Spoofing | PID/bundle target | high | mitigate | Resolve exact application, activate only it, confirm frontmost state, and revalidate PID/bundle before CGEvent. |
| T-LT01-07-T | Tampering | helper request/response | high | mitigate | Version/request ID, strict fields, 4096-byte caps, unknown-key rejection, fixed executable path, no shell. |
| T-LT01-07-R | Repudiation | native outcome | medium | mitigate | Finite request-correlated outcome codes with no content or identity logs. |
| T-LT01-07-I | Information Disclosure | target/clipboard/child output | high | mitigate | No clipboard text in protocol; target only active-session memory; raw output never reaches logs/errors/evidence. |
| T-LT01-07-D | Denial of Service | hung helper/activation | medium | mitigate | Bounded activation confirmation, two-second child timeout, AbortSignal kill, caps, bounded concurrency. |
| T-LT01-07-E | Elevation of Privilege | Accessibility/CGEvent to wrong target | critical | mitigate | Require trust and exact identity before event dispatch; never broaden permission, choose another target, or use shell fallback. |

Any critical or high finding blocks plan completion; medium findings require mitigation under ASVS L2.
</threat_model>
