<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer to preload | Untrusted document code requests a narrowly exposed capability. |
| preload/IPC to main | Privileged Electron and OS authority begins after exact sender/role/schema validation. |
| renderer session to local/external content | Navigation, permission, download, and network attempts cross the local-only boundary. |

## STRIDE Threat Register — ASVS L2

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-LT01-SC | Tampering | Electron/React/Zod runtime | high | mitigate | Consume only the reviewed exact Plan 01-02 lockfile; no install changes. |
| T-LT01-05-S | Spoofing | IPC sender/window role | high | mitigate | Immutable main registry, exact sender identity, main-frame check, and role-specific preloads. |
| T-LT01-05-T | Tampering | IPC payload/state | high | mitigate | Strict Zod parsing, unknown-key/bounds/session checks, and negative tests before dispatch. |
| T-LT01-05-R | Repudiation | privileged requests | medium | mitigate | Sanitized operation/outcome codes retain enough auditability without request content. |
| T-LT01-05-I | Information Disclosure | renderer snapshots/errors | high | mitigate | Role-redacted snapshots, allowlisted errors, CSP, and no raw Electron/target/result values. |
| T-LT01-05-D | Denial of Service | oversized/repeated IPC | medium | mitigate | Small channel-specific bounds, absolute 64 KiB ceiling, deduplication, and finite subscriptions. |
| T-LT01-05-E | Elevation of Privilege | preload and navigation | critical | mitigate | Sandbox/isolation/no Node, named bridge only, local files, denied navigation/popups/webviews/downloads/permissions/network. |

Any critical or high finding blocks plan completion; medium findings require mitigation under ASVS L2.
</threat_model>
