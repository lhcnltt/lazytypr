<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| global shortcuts/IPC to main session | OS and renderer events request lifecycle transitions in the sole authority. |
| main to clipboard/native adapters | Irreversible copy and privileged target activation/paste cross into OS state. |
| test composition to production composition | Test fakes must not create a runtime backdoor for privileged-port substitution. |

## STRIDE Threat Register — ASVS L2

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-LT01-SC | Tampering | runtime dependencies/native sources | high | mitigate | Exact lockfile and only Plan 01-06/01-07 reviewed adapters are composed. |
| T-LT01-08-S | Spoofing | session/hotkey/IPC events | high | mitigate | Main-generated current session ID, exact sender guards, main-owned shortcut callbacks. |
| T-LT01-08-T | Tampering | paste mode/output order | high | mitigate | Idle-only acknowledged setting, per-session snapshot, controller commit barrier, copy-before-paste tests. |
| T-LT01-08-R | Repudiation | user-visible outcome | medium | mitigate | Finite truthful Copied/Pasted/copy-only/Cancelled/Busy/Error outcomes without content. |
| T-LT01-08-I | Information Disclosure | clipboard/target/helper data | high | mitigate | Main-private values, redacted events, sanitized errors, no persistence/log/report paths. |
| T-LT01-08-D | Denial of Service | stuck shortcut/session/work | high | mitigate | Abortable fixed delays, two-second cleanup, idempotent teardown, retry state, repeated-cycle tests. |
| T-LT01-08-E | Elevation of Privilege | production/test port selection | critical | mitigate | Constructor-only test injection, fixed process.platform selection, no renderer/env/CLI override, unsupported-platform fail close. |

Any critical or high finding blocks plan completion; medium findings require mitigation under ASVS L2.
</threat_model>
