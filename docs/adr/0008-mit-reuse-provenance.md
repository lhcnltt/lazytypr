# ADR 0008: MIT publication, REUSE, and provenance

- Status: Accepted
- Date: 2026-07-31

## Decision

Publish original lazytypr work under MIT, copyright 2026 lhcnltt. Follow REUSE
3.3, preserve upstream licenses/notices, and record immutable provenance for all
copied or substantially adapted work. Generate notices and an SPDX or CycloneDX
SBOM for every release artifact.

## Consequences

The root license never relicenses dependencies, models, fonts, runtimes, or
adapted assets. Unknown obligations or missing provenance block release.
